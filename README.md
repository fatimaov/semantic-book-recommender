# Semantic Book Recommender

A learning project to build a **semantic book recommendation system** using Python, NLP, LLMs, and vector embeddings to recommend books based on their content.

## Tech Stack

Python · Jupyter Notebook · Pandas · NumPy · Matplotlib · Seaborn · LangChain · ChromaDB · Hugging Face · Gradio

## Progress

### 1. Exploratory Data Analysis (EDA)

- Downloaded a books dataset from Kaggle.
- Loaded and inspected the data using Pandas.
- Identified missing values and explored data quality.
- Visualized missing data and feature correlations using Seaborn and Matplotlib.

## Next Steps

Data cleaning → Text embeddings → Semantic search → Text classification → Recommendation interface
